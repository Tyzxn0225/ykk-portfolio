# 首页视频背景

当前使用的文件：`public/video/hero.mp4`

## 换视频的做法

把新视频命名为 `hero.mp4`（推荐）或 `hero.webm` 覆盖到这里即可自动生效，**不需要改任何代码**：

```
public/video/hero.mp4
```

只有一种情况需要改代码：新视频的结尾也带「个人主页收尾卡」这类不该出现在网站上的画面，
那就调整 `src/components/Hero.jsx` 顶部的 `LOOP_END`（单位秒），让它到点就跳回开头。

## 建议规格

| 项目 | 建议值 | 说明 |
| --- | --- | --- |
| 分辨率 | 1920×1080 或 2560×1440 | 全屏铺满，再高收益很小 |
| 时长 | 8 – 20 秒 | 循环播放，太短会看出重复 |
| 码率 | 4 – 8 Mbps | 更高质量会让首屏变慢 |
| 大小 | 建议 < 10 MB | 超过 15 MB 首屏会有明显等待 |
| 编码 | H.264 (mp4) | 兼容性最好；再补一份 VP9 (webm) 更省流量 |
| 声音 | 无 | 页面里已静音播放，带音轨只是白占体积 |

## 已知问题：源片四角带平台水印

这条素材是从社交平台下载的，**四个角都压着小红书水印，是烧进画面的**，无法用 CSS 干净地去掉：

```
左上「小红书」Logo     x 2.1% – 13.3%    y 3.6% – 12.1%
右上「白茶」+ 头像      x 83.0% – 96.9%   y 4.8% – 12.1%
左下「白茶」            x 4.8% – 18.6%    y 84.3% – 91.1%
右下 头像 + 号码        x 94.5% – 103.8%  y 83.3% – 96.2%
```

现在的处理方式：`src/styles/sections.css` 里的 `.hero__edgeMask` 用上下两条过渡带把它们压住。
顶部两块基本被导航栏和过渡带盖掉了，**底部两块在部分画面里仍能看到**。

试过的方案与结论：

- **CSS 局部模糊 / 取样同色覆盖**：补丁在移动画面上会变成可见灰斑，比水印更难看，已放弃。
- **放大裁切**：要同时把左右两组水印推出画面，横向需要放大 2.3 倍（画面只剩约 41% 宽），代价不可接受。

**推荐做法**：拿到无水印的原始素材后替换 `hero.mp4`，然后删掉 `.hero__edgeMask` 这一层，
并把 `.hero__scrim` 的强度相应减弱，画面会干净很多。

## 相关脚本

```bash
# 读取视频的时长 / 分辨率 / 编码（不依赖 ffmpeg）
python scripts/probe-video.py public/video/hero.mp4

# 在真实浏览器里验证视频是否真的在播放（而不是悄悄回退到静态图）
node scripts/verify-video.mjs --url http://127.0.0.1:5273/ --out shots

# 检查画面帧里还有没有平台水印的红色 Logo 像素
python scripts/check-watermark.py shots
```

## 没有视频时的行为

自动显示 `assets/hero/poster-*` 高清渲染图并带缓慢推移动效，**不会出现破图或黑屏**。
视频加载成功后才淡入覆盖图片；加载失败自动回退。

想直接换静态背景图（不用视频）：改 `scripts/process-images.py` 里 `PLAN["hero"]["poster"]` 的源文件名，然后运行：

```bash
pnpm assets poster
```
